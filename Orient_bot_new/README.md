# Orient Marketplace (Telegram Mini App)

Маркетплейс по Беларуси: объявления пользователей и магазины с модерацией.

## Запуск

1. Python 3.11+, `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `ADMIN_IDS`, `WEBAPP_URL`.
3. `uvicorn app:app --host 0.0.0.0 --port 8000`

При старте таблицы создаются/дополняются автоматически (недостающие колонки добавляются сами),
данные **не удаляются** — удалять `orders.db` после обновлений больше не нужно.

## Чтобы данные не пропадали после рестарта

* Локально: SQLite лежит в `orders.db` рядом с проектом (путь больше не зависит от папки запуска).
* На хостинге (Render и др.) диск временный — SQLite и `uploads/` стираются при каждом деплое.
  Используйте PostgreSQL в `DATABASE_URL` и постоянный диск для `UPLOAD_DIR`
  (готовый пример — `render.yaml`).

## Логика

* **Регистрация** = указать свой @username в Telegram (уникален). Без неё нельзя создавать объявления,
  заявки на магазин, покупать и оставлять отзывы.
* **Объявления**: только продажа, категории выбираются в фильтре. Телефон необязателен: «только сообщения» или
  «сообщения и звонки». Редактирование и удаление — в «Мои объявления».
* **Магазин**: один на пользователя. Создание и любое изменение (включая аватар) идут через модерацию.
  Контакты, город, доставка и самовывоз магазина подставляются во все его объявления автоматически.
  Объявления в магазин добавляет только владелец.
* **Модераторы** (`ADMIN_IDS` + добавленные через API) в `/admin`: заявки, блокировка (на N дней / навсегда),
  разблокировка и удаление магазинов.
* Страна — только Беларусь, шрифт — моноширинный.

## Оформление (Orient)

* Цвета: Burgundy `#800020`, Cream `#FFF5E1`. Тема «Orient» включена по умолчанию, есть тёмная и светлая.
* Шрифт интерфейса — SF Pro Display (на Android/Windows подставляется Inter).
* Фирменный шрифт **Soledago** (логотип, заголовки): положите файл в `static/fonts/` под именем
  `Soledago.woff2`, `Soledago.otf` или `Soledago.ttf`. Пока файла нет, используется похожий Shrikhand.
* Логотип и иконки — `static/img/`. `bot-avatar.png` — аватарка для бота в @BotFather (/setuserpic).
* Избранное хранится на устройстве пользователя (localStorage).
